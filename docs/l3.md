# Layer 3 — Cognitive Overload Balancer

Lift’s most original Flagsmith feature. The page watches for overload **on the device**, sends Flagsmith a single boolean identity trait, and lets a **segment** turn on Sensory-Safe mode. The UI decision is Flagsmith’s, not a local `if (score)`.

Nothing raw leaves the page: no mouse path, no click coordinates, no scroll log, no slider series. Only `overstimulated=true|false` is written with `flagsmith.setTrait` on the sticky identity (`lift_vid` cookie, or `?lift_identity=`).

## Demo

```bash
npm run l3:demo          # http://127.0.0.1:4175
npm run l3:bootstrap     # loopback Flagsmith at 127.0.0.1:8000
```

Open `http://127.0.0.1:4175`. The HUD (hide with `?hud=0`) shows the score, components, the trait Flagsmith reports back, inferred `sensory_safe` membership, and `l3_sensory_safe`.

## Score (5 second window)

| Component | What it measures | Weight |
|-----------|------------------|--------|
| Erratic mouse | Direction-change rate (turns > 60°) and jitter (path length / displacement) | 0.30 |
| Rage clicks | ≥ 3 clicks within 700 ms inside a 30 px radius | 0.25 |
| Scroll thrash | Reversals + high velocity | 0.25 |
| Simulated biometric | Demo-only 0–100 slider, labelled as simulated | 0.20 |

Each component is in `[0, 1]`. The weighted sum is the stress score.

## Hysteresis

- **Enter:** score ≥ **0.62** for **1.5 s** → `setTrait('overstimulated', true)`
- **Exit:** score < **0.38** for **8 s** → `setTrait('overstimulated', false)`
- **Cooldown:** 10 s after every transition, so the trait cannot flap
- **Fade:** ~2 s CSS transition; the page is not snapped back

The band between 0.38 and 0.62 cannot enter from calm or exit from Sensory-Safe.

## Flagsmith objects

Bootstrap (`scripts/l3-bootstrap.ts`) is idempotent and **loopback-only** unless `--allow-remote`. Against a fresh self-hosted Flagsmith at `127.0.0.1:8000` it signs up the first user, then creates the org, project, environment, master API key, and:

1. STANDARD flag `l3_sensory_safe`, default **off**, JSON config value
2. Segment `sensory_safe` with rule `overstimulated Exactly Matches true` (never `is_sensory_safe`). Bootstrap updates the existing segment in place.
3. Segment override that **enables** the flag for that segment

```bash
# Self-hosted (default) — writes gitignored .env + demo/l3/config.json
npm run l3:bootstrap

# Dry run (prints payloads, no token required)
npm run l3:bootstrap -- --dry-run

# Cloud / non-loopback (free tier only)
npm run l3:bootstrap -- --allow-remote
```

Tokens stay in the gitignored `.env`. Never commit them. Never show them on screen. stdout only prints masked keys.

After `setTrait`, the runtime calls `hasFeature('l3_sensory_safe')` and `getValue`. That is Flagsmith segment evaluation. If Flagsmith is unreachable (missing env key, SDK throw, network failure) the runtime **fail-opens**: the page stays in the normal flag-off state, the offline banner is shown, and `applySensorySafe(true)` is never called. `?l3_offline=1` is a labelled **OFFLINE FALLBACK — tests only** hook; it is not the production path.

Sticky identity is `lift-<uuid>` only. Anything else in `?lift_identity=` or the cookie is rejected.

## Sensory-Safe (all reversible, WCAG-safe)

When the flag is on:

- Pause **autoplay** video/audio only; a gesture-started play is left alone. Pause CSS animations when the flag’s `pauseMotion` is true (`prefers-reduced-motion` sets the fade to 0)
- Soften the flag’s ink/paper (or the documented defaults). Contrast of the **applied** pair stays ≥ WCAG AA **4.5:1** and is written to `data-lift-contrast`
- Reveal precomputed summaries from `data-lift-summary` (static strings, no LLM)
- Hide only `data-lift-promo` and `data-lift-marketing`. Cookie consent, errors, and legal copy stay visible
- Never hide `#checkout` / `data-lift-essential`. If focus is inside a node being hidden, it moves to `#checkout` or `<main>`
- Never change roles, names, or tabindex
- **Exit Sensory-Safe** is keyboard-reachable (button + Escape) and opts out for the rest of the session

## Files

| Path | Role |
|------|------|
| `runtime/l3-balancer.js` | Standalone browser module |
| `shared/l3-*.ts` | Score, hysteresis, contrast, identity |
| `scripts/l3-bootstrap.ts` | Admin API segment + flag + override |
| `scripts/serve-l3.ts` | Demo + `/runtime/` |
| `demo/l3/` | Busy demo page |
| `tests/unit/l3-*.test.ts` | Detectors, score, hysteresis, cooldown, contrast, bootstrap |
| `tests/e2e/l3-*.spec.ts` | Playwright full loop + no-flap |

Does not touch `runtime/runtime.js` (Phase A) or `selfhost/` (T3/T4).
